# NextXus HumanCodex

Federation member center, learning center and historical research center. Plain HTML, CSS and JavaScript on GitHub Pages. No build step, no server of our own, no keys in the code.

## What is here
- `index.html` front door
- `learn/` free courses (links to the course hub), paid tiers (links to Gumroad), roadmap
- `research/` one search across Wikipedia, OpenAlex, Crossref, Internet Archive, Wikidata and NASA images, plus "on this day"
- `ask/` source-checked claim tool (Wikipedia + Crossref, a model judges each source)
- `members/` Gumroad license-key check, tier and daily questions
- `assets/voice.js` speech in and out using the browser's own tools (free)

## Rules this site follows
- Gumroad is the source of truth for every title, price and description.
- Gumroad delivers every download and subscription. Custom work is done by hand after purchase.
- No key is ever stored in this repo. A visitor's own key stays in their browser. The first 3 questions per visitor run on the Federation's free server.
- Every score says what it measures and what sources it used. It is the best match from the sources checked, not proof.
- Readable without JavaScript where possible. Every page has a skip link and works by keyboard.

## Working on it for free
Edit any file on GitHub and commit. Pages publishes in about a minute. Nothing else is needed.
