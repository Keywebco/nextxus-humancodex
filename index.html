What this is, and how to check it yourself

The Federation is a free library and a set of honest AI tools that show where every answer came from, so a person can check it and not just trust it. Start here, in three clicks (about two minutes): 1. the live health report, a plain page a robot on GitHub rewrites every few hours, listing what is working and what is not; 2. the cost receipt, what it costs to run, dated, with each number marked measured or estimated; 3. the seal check, a daily check that the sealed rules have not been changed. The code and the sealed rules are public: the brain on GitHub. If you cannot verify a claim here in ten minutes without asking us, that is our fault, and we want to hear it: keywebco@gmail.com.
